# Мои дела — приложение с голосовым вводом

Один набор файлов: `index.html`, `manifest.json`, `sw.js` и иконки. Всё работает **офлайн**, данные хранятся только в браузере.

## 1. Установить на Android (2 способа)

### Способ А — без интернета и без сервера (самый быстрый)
1. Скачайте `index.html` на телефон (или откройте в браузере).
2. Откройте файл в **Chrome**: «⋮» → «Открыть» → выбрать `index.html`.
3. «⋮» → **«Добавить на главный экран»**.
   Иконка появится как приложение. Минус: файл открывается из хранилища — часть функций (установка через PWA, обновления) ограничена.

### Способ Б — как настоящее приложение (PWA)
Нужен любой https-адрес с этими файлами. Ссылки живут примерно 6 часов:
1. Загрузите **всю папку** `planner-app` на https://app.netlify.com/drop — получите ссылку.
2. Откройте ссылку **в Chrome на Android**.
3. Кнопка **«Установить»** вверху страницы (или «⋮» → «Установить приложение»).
4. Приложение встанет в систему, откроется в полный экран и будет работать офлайн.

Постоянный вариант: GitHub Pages, Cloudflare Pages или Vercel (бесплатно, загрузил папку — получил постоянный адрес).

### iPhone
Safari → «Поделиться» → «На экран Домой».

## 2. Как вносить дела

- **🎙 Голосом** — Chrome/Edge (Android и десктоп). Говорите по одному делу, пауза = новое дело.
- **Микрофон на клавиатуре** (Gboard / iOS) — работает везде, точнее для русского. Нажмите на текстовое поле → 🎤 → диктуйте.
- **Вставить готовый список** — из заметок, мессенджера, любого текста.

Потом «Разобрать →» — приложение вытащит даты, время, длительности, важность и категории. Проверяете в предпросмотре → «Добавить всё».

## 3. Что понимает разбор

| Параметр | Примеры |
|---|---|
| Даты | сегодня, завтра, послезавтра, в пятницу, через 2 дня, через неделю, 25.11, 5 декабря |
| Время | в 9, в 14:30, утром (09:00), вечером (19:00), в 3 дня (15:00) |
| Длительность | 15 минут, полчаса, час, 1,5 часа, 2 ч |
| Важность | важное → важное; срочно / критично → критичное |
| Категории | работа, дом, здоровье, финансы, учёба, личное (+ угадывание по смыслу) |
| Разделители | перевод строки, `;`, «потом», «затем», маркеры `-` и `1)` |

## 4. Перенос и сохранность данных

- Данные лежат в `localStorage` **этого** браузера.
- **Экспорт в файл** / **Импорт из файла** — в блоке «Как этим пользоваться».
- ⚠️ Если очистить данные браузера — дела пропадут. Периодически делайте экспорт (или держите постоянный https-адрес: тогда данные не потеряются при очистке, т.к. браузер держит их для сайта).

## 5. Ограничения

- Распознавание речи Chrome для русского **облачное** (Google) и не идеальное — отсюда правка в предпросмотре.
- Нет синхронизации между устройствами (для этого — Todoist/TickTick).
- Нет push-напоминаний.

## 6. Тесты

Парсер и интерфейс покрыты автотестами (28 проверок): даты, относительные даты, разделители, длительности, категории, предпросмотр, добавление, отметка выполнения, экспорт, офлайн-файлы.
